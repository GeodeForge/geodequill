Write in your own voice.

GeodeQuill teaches your AI app how you write. Give it a few things you wrote, and it writes or rewrites anything in your voice, in the tone you pick.

What it does

Learns your voice

From emails, posts or letters you wrote. Add transcripts of you talking, and it learns how you sound out loud too.

Keeps voices and tones

A work voice, a casual voice, a character, or one of five built-in authors: Twain, Austen, Dickens, Lincoln and Wilde. Pick a tone each time: formal, casual, friendly, intimate and eight more.

Reviews every draft

Against your own habits, and against the patterns that make text read as machine-written, then fixes what's off. Then it offers to measure the draft exactly with its checker; say yes and you see your app run it.

What it won't do

  • Promise to get past AI detectors. They guess, and they're often wrong. It never gives a score.
  • Make things up about you. It is built not to invent memories, quotes, numbers or opinions, and leaves a [bracketed note] for details only you know. Read the draft before you send it: no check catches everything.
  • Put words in a real person's mouth. A famous person's voice is always labelled "in the style of". It only goes looking for someone's writing when that writing is free of copyright.
  • Use tricks. No invisible characters, no planted typos.

Looking for an AI humanizer?

Plenty of tools promise to "humanize" AI text so detectors miss it. GeodeQuill doesn't make that promise, because detectors guess and nobody can guarantee their verdict. What it does is make the writing sound like you: your rhythm, your words, your habits. It also takes out the patterns that make text read as machine-written.

Where it works

ChatGPT, on the web and your phone

Add it on chatgpt.com. OpenAI's help page counts the website and the phone app as one place, so your phone should get it too; we haven't tested that yet. Skills aren't on every ChatGPT plan yet.

Claude, on the web and the desktop app

Every Claude plan, including Free. The phone app can't add skills: add it once from a computer, on the Claude website or in the desktop app, and the phone app uses it from then on.

Other apps that read skills

Codex, GitHub Copilot, Gemini CLI, Cursor, VS Code and more. Apps that take MCP connectors work too.

Any language

It writes in any language. It looks for machine-writing phrases in English, Chinese (simplified and traditional) and Spanish. In every language it checks punctuation, layout and paragraph rhythm, and sentence rhythm wherever the writing marks where sentences end (Thai, Lao and Tibetan don't). For a language with no phrase list, its report says when the phrase check didn't run.

GeodeQuill runs inside your AI app. This page can't do the writing itself, because that would need a paid AI server, and we don't run one.

Install it

Pick the app you use. Each one takes a couple of minutes.

ChatGPT
  1. Download the skill file.
  2. On chatgpt.com, in the sidebar, select Plugins, then the Skills tab.
  3. Select Create, then Upload from your computer, and choose the file.
  4. Wait for ChatGPT to check it. Then start a chat and say "Set up my voice."

No Skills tab? Your plan doesn't have skills yet. OpenAI's help pages disagree on which plans do: one names the business plans, another says every paid plan except Free and Go.

Claude
  1. Download the skill file.
  2. In Claude, go to Customize, then Skills.
  3. Select +, then Create skill, then Upload a skill, and choose the file.
  4. Start a chat and say "Set up my voice."

Skills need code execution turned on in Claude's settings.

In the Claude desktop app you can install the plugin file instead. In Claude Code, type /plugin marketplace add GeodeForge/geodequill, then /plugin install geodequill@geodeforge.

Codex, Copilot, Gemini CLI, Cursor and others
  1. Download the skill file.
  2. Unzip it into your app's skills folder. Your app's help pages say where that folder is.
  3. Say "Set up my voice."
Apps that take MCP connectors
  1. Download the connector file and unzip it.
  2. Follow the README inside. You need Python 3.10 or later.

ChatGPT doesn't take this kind of connector. Use the skill file there.

AI apps sometimes answer a short request themselves without opening GeodeQuill. Anthropic's own guide for people who write skills says Claude tends to skip a skill on a short, simple request, even when the request matches the skill's description exactly. To make sure it's used, start with "Use GeodeQuill to…", for example "Use GeodeQuill to write a thank-you note like Jane Austen."

Already using GeodeQuill? Your saved voices are kept. Add the new file the same way you added the first one; if your app says the skill already exists, delete the old one first. In Claude Code, run claude plugin marketplace update geodeforge and then claude plugin update geodequill@geodeforge in a terminal, then restart Claude Code.
